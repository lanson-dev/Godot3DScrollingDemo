# 3C Technical Notes

This demo composes editable 3D scenes for **Character, Camera, and Control** in a side view. `scenes/gameplay/main.tscn` retains a ramp, raised platform, static cover, player, and combat NPCs. The environment has no harvesting or destruction. [中文](3C.zh.md).

| System | Scenes, scripts, and parameters |
| --- | --- |
| Character | `scenes/actors/player.tscn` and `enemy.tscn` each combine a `CharacterBody3D`, health, weapons, and the shared visual scene. `scripts/actors/actor.gd` handles ground, slopes, jumps, and crouching. |
| Animation | `scenes/actors/character_visual.tscn` mounts the skeleton, animation tree, and two gun models. `scripts/actors/character_visual.gd` and `aim_modifier.gd` update aiming and grip. |
| Camera | The main scene's `SideCamera` and `scripts/camera/side_camera.gd` control follow motion, look-ahead damping, and gun-specific aim offsets. |
| Input | `scenes/ui/mobile_controls.tscn` provides two-sided touch controls; `demo_settings.tscn` handles NPC spawning, respawn, and control mode switching. |
| Guns | `resources/weapons/rifle.tres` and `shotgun.tres` configure damage, fire rate, ammo, spread, crosshair, and camera offset. `scenes/weapons/` holds gun models, muzzles, and projectiles; `resources/weapons/muzzle/` holds flash profiles. |
| NPC | `scenes/actors/enemy.tscn` and `scripts/actors/enemy.gd` implement patrol, detection, chase, fire, hit, and death. Inspector properties expose sight range, reaction time, patrol distance, and firing range. |

Shots originate at the muzzle and static walls block them. Characters share one visual scene while health, weapons, and behavior belong to each instance. The crosshair displays gun spread; muzzle flashes and aiming camera offsets are configured per gun. See [ASSETS.md](ASSETS.md) for asset sources and licenses.
