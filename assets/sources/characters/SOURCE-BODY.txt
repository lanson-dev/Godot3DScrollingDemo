Adaptation:
- Added two editable native Blender keys, BodySlim and BodyHeavy, on Body; default weights are zero. Body contains 3053 mapped vertices / 13164 corners. Each key moves 641 vertices; 1430 protected positions, including hands/boots, remain unchanged.
- Verified mapping through Body.matrix_world and Blender Z-up to glTF Y-up. Maximum position error was 5.960464477539062e-7 m; UV and skin-weight mapping errors were zero.
- Extracted only new POSITION/NORMAL targets. Appended 20 accessors and 20 bufferViews; retained the original 355684-byte BIN prefix exactly. Removing the added morph references and restoring the original buffer length reproduces the original JSON records exactly.
- Existing node/bone names, skin binds, 17 animations, materials, base positions/normals and old references are preserved. The source survivor.glb remains separate and unchanged.
- Full Blender round-trip export was rejected because it resampled existing animation channels and changed small normal/vertex-split details. Its failed baseline remains failed; it was not used as the runtime derivative.
- A normal full export of this Blend is therefore not equivalent to the append-only derivative. The preserved original GLB and the new shape deltas are both needed to preserve the calibrated original data.
